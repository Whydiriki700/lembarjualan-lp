Ketentuan pembelian

Satu pembelian berlaku untuk satu pemilik usaha. File boleh dipakai untuk semua produk dan toko milik pembeli sendiri, dan tidak boleh dijual kembali, dibagikan, atau diunggah ulang untuk orang lain.

File dikirim sesudah pembayaran terverifikasi. Bantuan pemasangan lewat chat berlaku untuk pemasangan pertama sampai halaman online.

Update template berikutnya termasuk hanya di paket Pro. Harga dan isi paket yang berlaku adalah yang tertulis di halaman harga saat pemesanan.
